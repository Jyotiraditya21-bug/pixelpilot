# PixelPilot Community Guidelines

PixelPilot is an open-source collaboration space for engineers building self-healing test automation.

## Core Expectations

- Treat all collaborators with courtesy, professionalism, and patience.
- Provide thoughtful and constructive reviews on pull requests and issues.
- Keep technical discussions grounded in evidence, benchmarks, and reproducible facts.
- Do not engage in hostile, harassing, or exclusionary communication.

## Escalation

If you encounter behavior that violates these principles, please contact the repository maintainer directly.
